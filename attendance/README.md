# 출퇴근 기록

출근 ☀️ / 퇴근 🌙 아이콘을 누르면 **구글 시트**에 바로 기록되는 웹 앱이에요.
사람마다 이름·사번·시트 탭·시트 주소를 따로 설정할 수 있고, 한 기기(사무실 태블릿 등)를 여러 명이 같이 써도 돼요.

```
attendance/
├─ index.html          앱 화면 (출근·퇴근 아이콘)
├─ app.js              앱 동작 (설정 저장, 전송, 오프라인 보관)
├─ apps-script/Code.gs 구글 시트에 붙여 넣는 서버 코드
└─ icon*.png/svg, manifest.webmanifest  홈 화면 아이콘
```

## 1. 구글 시트 준비 (한 번만, 관리자)

1. 새 구글 시트를 만들어요. (예: `2026 출퇴근부`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 열어요.
3. 기본 코드를 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여 넣고 저장해요.
4. (권장) 코드 맨 위 `var SECRET = '';` 를 `var SECRET = '아무비밀번호';` 처럼 바꿔요.
   주소를 아는 다른 사람이 함부로 기록을 넣지 못하게 막아 줘요.
5. 오른쪽 위 **배포 → 새 배포** → 유형 ⚙️ **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포** → 권한 승인 → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사해요.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전** 으로 다시 배포해야 반영돼요. URL은 그대로예요.

## 2. 사람마다 설정 (각자, 앱에서)

앱을 열면 설정 창이 떠요. (나중엔 오른쪽 위 ⚙️ 또는 이름을 눌러 바꿀 수 있어요.)

| 항목 | 설명 |
|---|---|
| 이름 | 시트에 남는 이름 |
| 사번 / 소속 | 선택. `전체기록` 탭에 함께 남아요 |
| 시트 탭 이름 | 이 사람 기록이 쌓일 탭. 비우면 이름으로 자동 생성 |
| 웹 앱 주소 | 1단계에서 복사한 URL. 사람마다 다른 시트를 쓰려면 다른 URL을 넣으면 돼요 |
| 비밀키 | Code.gs 의 `SECRET` 과 같게 |
| 구글 시트 링크 | 선택. 넣으면 "시트 열기" 버튼이 생겨요 |
| 확인 묻기 / 메모 | 실수 방지 확인창, 외근·재택 같은 메모 입력 |

**연결 테스트** 버튼으로 바로 확인할 수 있어요. 새 사람을 추가하면 주소·비밀키는 지금 사람 것으로 미리 채워져요.

설정은 그 기기의 브라우저에만 저장돼요. (다른 폰에서 쓰려면 그 폰에서 한 번 더 설정)

## 3. 시트에 남는 모양

**`전체기록` 탭** – 버튼 누를 때마다 한 줄

| 기록시각 | 날짜 | 시각 | 구분 | 이름 | 사번/소속 | 탭 | 기기시각 | 메모 |
|---|---|---|---|---|---|---|---|---|
| 2026-11-19 09:01:00 | 2026-11-19 | 09:01:00 | 출근 | 홍길동 | 2024001 · 행정팀 | 홍길동 | … | |

**사람별 탭 (예: `홍길동`)** – 하루 한 줄, 근무시간 자동 계산

| 날짜 | 출근 | 퇴근 | 근무시간 | 메모 |
|---|---|---|---|---|
| 2026-11-19 | 09:01:00 | 18:15:00 | 9시간 14분 | |

- 출근을 여러 번 누르면 **첫 출근 시각**이, 퇴근을 여러 번 누르면 **마지막 퇴근 시각**이 남아요. (`전체기록`엔 모두 남아요)
- 시각은 구글 서버 기준 한국 시간(Asia/Seoul)이라 폰 시계를 바꿔도 조작되지 않아요.
- 인터넷이 끊겼을 때 누른 기록은 폰에 보관했다가 연결되면 자동으로 보내고, 이때는 **실제로 누른 시각**으로 기록돼요.
